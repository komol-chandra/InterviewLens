# A_InterviewLens — Interview & CSE Prep Workspace

এটা একটা **রিইউজেবল, লং-টার্ম ওয়ার্কস্পেস** — CSE ফান্ডামেন্টাল স্টাডি, কোম্পানি-ভিত্তিক ইন্টারভিউ প্রস্তুতি, জব অ্যাপ্লিকেশন ট্র্যাকিং, এবং রেজুমে/কভার লেটার ম্যানেজমেন্টের জন্য। প্রতিটা টপ-লেভেল ফোল্ডার নম্বর দিয়ে শুরু (`00-`, `01-`, ...) — অগ্রাধিকার/অর্ডার বোঝার জন্য।

## ফোল্ডার স্ট্রাকচার

```
A_InterviewLens/
├── 00-templates/           ← নতুন কোম্পানি প্রেপ বুটস্ট্র্যাপ করার জন্য reusable templates
├── study/                  ← 🎯 সব স্টাডি + প্ল্যান + ট্র্যাকার + প্রেপ মেমরি (বিস্তারিত: study/README.md)
│   ├── 00-plan/  _memory/  01-cse-fundamentals/  02-problem-solving/  03-roles/
├── 02-companies/           ← প্রতিটা কোম্পানি/রোলের জন্য আলাদা সাবফোল্ডার
├── 03-job-applications/    ← জব অ্যাপ্লিকেশন ট্র্যাকার ও ইমেইল টেমপ্লেট
├── 04-resume-cover-letter/ ← CV ও কভার লেটার (current + archive)
└── 05-research-writeups/   ← একাডেমিক/রিসার্চ পেপার ও লেখা
```

### `00-templates/`
`FOLDER_STRUCTURE.md`, `README.md`, `TODO.md` — খালি টেমপ্লেট, নতুন কোম্পানি প্রেপ শুরু করার সময় `02-companies/<company-name>/`-এ কপি করে ব্যবহার করো। `README.md`-এর "Answer Pattern" অংশটাই Claude Code দিয়ে টপিক কনটেন্ট জেনারেট করার একমাত্র নিয়ম। `generate-topics-prompt.txt` ও `company-research-prompt.md` — কনটেন্ট জেনারেশন/কোম্পানি রিসার্চের জন্য রেডিমেড প্রম্পট।

### `study/` (আগে `01-cse-fundamentals/` নামে টপ-লেভেলে ছিল)
সব স্টাডি কাজ এখন `study/`-এর ভেতরে: অ্যাক্টিভ প্ল্যান (`00-plan/`), টাইপ-ভিত্তিক প্রেপ মেমরি (`_memory/`), জেনেরিক CS (`01-cse-fundamentals/`), DSA PDF (`02-problem-solving/`), রোল-নির্দিষ্ট প্রেপ (`03-roles/`)। Claude সেশন প্রোটোকল: `study/CLAUDE.md`। নিচের অংশটা `study/01-cse-fundamentals/`-এর বর্ণনা:

"CS Global Study Dir" — জেনেরিক, রিইউজেবল CS কনটেন্ট, **সব কোম্পানির প্রেপে শেয়ার্ড**। ভেতরে দুই ভাগ: `theory/` (১৫টা কনসেপ্ট টপিক, প্রতিটা নিজের ফোল্ডারে নোট/চিটশিট/ডিপ-ডাইভ ফাইল সহ) আর `practical/` (DSA প্যাটার্ন-ভিত্তিক প্র্যাকটিস, easy/medium/hard গ্রেডেড)। বিস্তারিত `01-cse-fundamentals/README.md`-এ। কোনো কোম্পানি-স্পেসিফিক ফোল্ডারে এই কনটেন্ট ডুপ্লিকেট করা হবে না — নতুন জেনেরিক টপিক লাগলে এখানেই যোগ করো।

### `02-companies/`
প্রতিটা কোম্পানি/রোলের নিজস্ব সাবফোল্ডার (যেমন `senior-software-engineer/`, `welldevs/`, `automatrix/`) — শুধু সেই কোম্পানির জন্য প্রাসঙ্গিক জিনিস: TODO/progress, কোম্পানি রিসার্চ নোট, ইন্টারভিউ-স্ক্রিনশট, কোম্পানি-স্পেসিফিক স্টাডি/প্রবলেম-সলভিং কনটেন্ট। নতুন কোম্পানি শুরু করতে `00-templates/`-এর ফাইলগুলো এখানে একটা নতুন সাবফোল্ডারে কপি করো।

### `03-job-applications/`
`tracker-screenshots/` — যেসব জবে আবেদন করা হয়েছে তার ট্র্যাকার স্ক্রিনশট। `email-template.txt` — জেনেরিক অ্যাপ্লিকেশন ইমেইল টেমপ্লেট।

### `04-resume-cover-letter/`
`current/` — সর্বশেষ, ক্যানোনিক্যাল CV ও কভার লেটার (এখান থেকেই সবসময় ব্যবহার করবে)। `archive/` — আগের ভার্সনগুলো, তারিখ দিয়ে নামকরণ করা, শুধু রেফারেন্সের জন্য রাখা।

### `05-research-writeups/`
জব প্রেপের বাইরে একাডেমিক/রিসার্চ লেখা।

## নামকরণের নিয়ম
- প্রতিটা টপ-লেভেল ফোল্ডার নম্বর দিয়ে শুরু — অগ্রাধিকার/অর্ডার বোঝার জন্য
- প্রতিটা কোম্পানি ফোল্ডারের ভেতরে ফাইল/সাবফোল্ডার নম্বর দিয়ে অর্ডার করা (যেখানে প্রযোজ্য)
- CV/কভার লেটারের পুরনো ভার্সন সবসময় `archive/`-এ তারিখ-সহ নাম দিয়ে রাখা হয়, `current/`-এ শুধু সর্বশেষ ভার্সন থাকবে
