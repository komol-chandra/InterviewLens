# study/ — Claude Interview-Prep Brain

এই ফোল্ডারে কাজ শুরু করলে **Sokrio কোডবেসের নিয়ম প্রযোজ্য নয়** — এটা Komol-এর জব ইন্টারভিউ প্রস্তুতির ওয়ার্কস্পেস। Komol-এর সব কাজের অভিজ্ঞতা = **Sokrio** (২০২৩–বর্তমান), তার আগে SoftArch ও Am Coders।

## Session Start Protocol (MANDATORY)

প্রতিটা সেশনের শুরুতে, অন্য কিছুর আগে:

1. `_memory/handoff.md` — গতবার কোথায় থেমেছি, আজ কী করার কথা
2. `00-plan/TODO.md` — আজকের দিনের চেকলিস্ট (তারিখ মিলিয়ে দেখো)
3. `_memory/weak-areas.md` — কোন টপিকে দুর্বল, সেগুলোতে জোর দাও
4. নতুন ডক জেনারেট করার আগে: `00-plan/doc-tracker.md`-এ দেখো ডকটা আগে থেকে আছে কি না

## Session End Protocol (MANDATORY)

1. `00-plan/TODO.md` — শেষ হওয়া টাস্ক টিক দাও
2. `00-plan/doc-tracker.md` — নতুন/আপডেট হওয়া প্রতিটা ডকের সারি আপডেট করো (status, তারিখ)
3. যে ফোল্ডারে কাজ হয়েছে সেই ফোল্ডারের `TODO.md` আপডেট করো
4. `_memory/` — যা শিখলাম/সিদ্ধান্ত নিলাম সেটা সঠিক টাইপের ফাইলে লেখো (নিচের টেবিল দেখো)
5. `_memory/handoff.md` ওভাররাইট করো: আজ কী হলো, পরের সেশনে প্রথম কাজ কী

## Memory Types (`_memory/`)

| Type | ফাইল | কখন লিখবে |
|------|------|-----------|
| `profile` | `profile.md` | Komol সম্পর্কে স্থায়ী তথ্য বদলালে (অভিজ্ঞতা, টার্গেট রোল, সময়, ভাষা) |
| `story` | `story-bank.md` | নতুন STAR স্টোরি বা পুরনো স্টোরিতে নতুন ডিটেইল/মেট্রিক |
| `gap` | `weak-areas.md` | প্রতিটা স্টাডি সেশন / মক শেষে self-rating (০–৩) বদলালে |
| `log` | `interview-log.md` | আসল ইন্টারভিউ রাউন্ডের পর — কী প্রশ্ন এসেছিল, কেমন উত্তর দিলাম |
| `decision` | `decisions.md` | রোল, স্যালারি, প্ল্যান বদল — কী ও **কেন** |
| `handoff` | `handoff.md` | প্রতিটা সেশনের শেষে (সবসময় ওভাররাইট, history রাখে না) |

নিয়ম: একই তথ্য দুই জায়গায় লিখবে না। `handoff` ছাড়া বাকি সব append/update — মুছবে না, ভুল হলে ~~strike~~ করে কারণ লেখো।

## Folder Rules

- `01-cse-fundamentals/` → **জেনেরিক** CS কনটেন্ট (যেকোনো কোম্পানিতে কাজে লাগবে)। কোম্পানি-নির্দিষ্ট কিছু এখানে না।
- `03-roles/<company-role>/` → **শুধু ওই রোলের** জিনিস। জেনেরিক টপিক এখানে কপি না করে `01-`-এর ফাইলে লিংক দাও, এখানে শুধু "delta" (রোল-নির্দিষ্ট অতিরিক্ত অংশ) লেখো।
- নতুন ফোল্ডার বানালে সেখানে একটা `TODO.md` রাখো, আর প্যারেন্ট `TODO.md`-এ এক লাইন যোগ করো।
- নম্বর দেওয়া ফোল্ডার/ফাইলের নম্বর কখনো রিইউজ বা শিফট করবে না।

## Doc Generation Rules (Answer Pattern)

`../00-templates/README.md`-এর Answer Pattern-ই মূল নিয়ম, সাথে দুটো যোগ:

1. **ভাষা:** বাংলা, টেকনিক্যাল টার্ম ইংরেজিতে (Index, Event Loop, Middleware)। কিন্তু **ইন্টারভিউতে মুখে বলার লাইন** (pitch, STAR-এর মূল বাক্য) ইংরেজিতে — কারণ ইন্টারভিউ ইংরেজিতে হবে।
2. **প্রতিটা প্রশ্নের শেষে `🔗 Sokrio link:`** — এক লাইনে Komol-এর Sokrio অভিজ্ঞতার কোন অংশ এই উত্তরের প্রমাণ (`_memory/story-bank.md`-এর স্টোরি ID দিয়ে, যেমন `S2`)। মিল না থাকলে সৎভাবে লেখো "সরাসরি অভিজ্ঞতা নেই — এভাবে বলো: ..."।
3. প্রতিটা নতুন ডকের একদম উপরে: `> Tracker ID: FN-xx · Generated: YYYY-MM-DD · Source: ...`

## Honesty Rule

CV-র প্রতিটা সংখ্যা (85%, 65%, 27%, 20%, 99.9%) ইন্টারভিউয়ার চ্যালেঞ্জ করতে পারে। স্টোরি বা উত্তর লেখার সময় কখনো নতুন সংখ্যা বা ঘটনা বানাবে না — অজানা ডিটেইল `[Komol পূরণ করবে]` দিয়ে ফাঁকা রাখো।
