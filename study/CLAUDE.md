# study/ — Claude Interview-Prep Brain

এই ফোল্ডারে কাজ শুরু করলে **Sokrio কোডবেসের নিয়ম প্রযোজ্য নয়** — এটা Komol-এর জব ইন্টারভিউ প্রস্তুতির ওয়ার্কস্পেস। Komol-এর সব কাজের অভিজ্ঞতা = **Sokrio** (২০২৩–বর্তমান), তার আগে SoftArch ও Am Coders।

## Session Start Protocol (MANDATORY)

প্রতিটা সেশনের শুরুতে, অন্য কিছুর আগে:

1. `1-me/handoff.md`: গতবার কোথায় থেমেছি
2. `START-HERE.md`: আজকের তারিখের সারি = আজকের কাজ
3. `1-me/weak-areas.md`: কোন টপিকে দুর্বল, সেগুলোতে জোর দাও
4. নতুন ডক বানানোর আগে `tracker.md`-এ দেখো আগে থেকে আছে কি না

## Session End Protocol (MANDATORY)

1. `START-HERE.md`: আজকের সারিতে ✔ (অর্ধেক হলে `~` + কারণ)
2. `tracker.md`: নতুন/পড়া ডকের সারি (Status, Studied, Conf) আর DSA কাউন্ট
3. `1-me/`: যা শিখলাম/সিদ্ধান্ত নিলাম, সঠিক টাইপের ফাইলে (নিচের টেবিল)
4. `1-me/handoff.md` ওভাররাইট: আজ কী হলো, পরের সেশনে প্রথম কাজ কী

> আর কোনো TODO ফাইল নেই। অগ্রগতি থাকে **শুধু** `START-HERE.md` (দিন) আর `tracker.md` (ডক + DSA)-এ (D10)।

| Type | ফাইল | কখন লিখবে |

| `story` | `story-bank.md` | নতুন STAR স্টোরি বা পুরনো স্টোরিতে নতুন ডিটেইল/মেট্রিক |

| `log` | `interview-log.md` | আসল ইন্টারভিউ রাউন্ডের পর: কী প্রশ্ন এসেছিল, কেমন উত্তর দিলাম |

| `1-me/` | Komol সম্পর্কে তথ্য (মেমরি টাইপ ওপরে) | স্টাডি কনটেন্ট |

- ভেতরের টপিক-ফোল্ডারের নম্বর (`4-library/cs/NN-`, `3-practice/dsa/NN-`) কখনো রিইউজ বা শিফট করবে না।

## Doc Generation Rules (Answer Pattern)

`../00-templates/README.md`-এর Answer Pattern-ই মূল নিয়ম, সাথে দুটো যোগ:

1. **ভাষা:** বাংলা, টেকনিক্যাল টার্ম ইংরেজিতে (Index, Event Loop, Middleware)। কিন্তু **ইন্টারভিউতে মুখে বলার লাইন** (pitch, STAR-এর মূল বাক্য) ইংরেজিতে — কারণ ইন্টারভিউ ইংরেজিতে হবে।
2. **প্রতিটা প্রশ্নের শেষে `🔗 Sokrio link:`** — এক লাইনে Komol-এর Sokrio অভিজ্ঞতার কোন অংশ এই উত্তরের প্রমাণ (`1-me/story-bank.md`-এর স্টোরি ID দিয়ে, যেমন `S2`)। মিল না থাকলে সৎভাবে লেখো "সরাসরি অভিজ্ঞতা নেই — এভাবে বলো: ..."।
3. প্রতিটা নতুন ডকের একদম উপরে: `> Tracker ID: FN-xx · Generated: YYYY-MM-DD · Source: ...`

## Honesty Rule

CV-র প্রতিটা সংখ্যা (85%, 65%, 27%, 20%, 99.9%) ইন্টারভিউয়ার চ্যালেঞ্জ করতে পারে। স্টোরি বা উত্তর লেখার সময় কখনো নতুন সংখ্যা বা ঘটনা বানাবে না — অজানা ডিটেইল `[Komol পূরণ করবে]` দিয়ে ফাঁকা রাখো।
